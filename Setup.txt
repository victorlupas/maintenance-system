==========================================
PROJECT SETUP GUIDE (BACKEND + FRONTEND)
==========================================

This document explains how to install and run the backend and frontend for the Predictive Maintenance System.

=====================
1. SYSTEM REQUIREMENTS
=====================

You must have the following installed on your machine:

Required

Python 3.10+

Node.js (LTS version 18.x or 20.x)
→ Installing Node.js also installs npm and npx

=====================
2. BACKEND SETUP (FastAPI)
=====================
1. Navigate to the backend folder
cd backend

2. Create a virtual environment (if it doesn't exist)

Windows:

python -m venv venv
venv\Scripts\activate

3. Install Python dependencies
pip install -r requirements.txt

4. Run the FastAPI server
uvicorn main:app --reload

5. Access the backend

API root: http://localhost:8000

API docs (Swagger): http://localhost:8000/docs

=====================
3. FRONTEND SETUP (React + Vite)
=====================
1. Navigate to the frontend folder
cd frontend

2. Install Node dependencies
npm install


This installs:

React

Vite

TailwindCSS

Axios

Recharts

Lucide-react

And all other packages listed in package.json

3. Start the development server
npm run dev

4. Access the frontend

It will tell you the URL (usually):

http://localhost:5173

=====================
4. COMMON ISSUES
=====================
Node command not found

Reinstall Node.js (LTS) from: https://nodejs.org/

Python dependencies missing

Re-run:

pip install -r requirements.txt

CORS errors in browser

Make sure backend is running at http://localhost:8000

.

Frontend environment variables

If needed, create:

frontend/.env

VITE_API_URL=http://localhost:8000
